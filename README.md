# Ztool

`Ztool` lets you register a custom "Open With `<your app>`" entries inside a Ztool right-click submenu for:
- files
- folders
- folder background (inside a folder / desktop background)

## Design

Old style desktop app to make it clean, minimalistic (inspired by [ghidra](https://github.com/NationalSecurityAgency/ghidra) app)
